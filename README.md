迷你世界地图转blender可视化模型
声明：此工具用于将迷你世界的地图转换为blender的可视化模型，该工具的全部内容均由豆包ai生成，本人仅作为人在回路的节点。仅供研究禁止其他用途，造成的影响后果自负。
使用方法：将表data文件夹里的lua代码复制到地图的脚本里，在“POS1”和“POS2”里修改自己的区域对角坐标，运行后点击任意方块或放置任意方块即可触发扫描。等待脚本运行完成，运行本文件夹里的“拼接csv.py”，会在csv文件夹里生成文件。下载blender3.6/4.2版本（适配最好）进入blender，在偏好设置里安装插件文件夹里的”MINIX_Block_Importer.py“后打开N面板，即可看到该工具，初次使用要设置一下文件路径，选择本文件夹的路径即可。点击选择csv导入按钮，选择你的地图csv数据，等待导入完成。插件文件夹里的”贴图材质批量调整.py“复制到blender的脚本里运行。
原理：使用迷你世界的lua环境，读取所选区块的所有实体方块结构数据，输出到日志log文件里，用py脚本对方块进贴图和颜色的映射最终在blender里还原出方块的体貌。
